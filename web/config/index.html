Starting

This browser cannot connect to the keyboard

The page talks to the keyboard through Web Serial (USB) and Web Bluetooth. Chrome and Edge on Windows, macOS, Linux and ChromeOS have them; Firefox and Safari do not.

Without a keyboard: try the demo.

Connect the keyboard

USB: plug in the cable and click Connect USB. Chrome lists the keyboard twice (two serial ports, on Linux with the udev rules "Rainy 75 Pro Console" and "Rainy 75 Pro Studio"): choose the console port, or either, the page finds the right one.

Bluetooth: the keyboard must be paired with this computer. Click Connect Bluetooth and choose "Rainy 75 Pro".

Bluetooth is not available in this browser. In Chrome on Linux, turn on chrome://flags/#enable-web-bluetooth and restart Chrome.

USB needs Chrome or Edge on a desktop computer.

Changes apply at once and are stored on the keyboard. Settings guide. Without a keyboard: demo.
